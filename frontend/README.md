# Ink Readable Frontend

React, TypeScript and Vite frontend for Ink Readable.

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

The project uses:

- Vitest with `happy-dom` for tests.
- Oxlint for linting.
- Oxfmt for formatting.
- shadcn/ui with Tailwind CSS for components.
- Lucide React for icons.
